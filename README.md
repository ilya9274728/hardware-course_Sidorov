dotnet build собирает программу. dotnet run собирает её и запускает.
После сборки в bin/Debug/net10.0/ обычно появляются файлы программы, отладки и настроек запуска.
Компилятор превращает C#-код в инструкции. Процессор не понимает текст C# напрямую.
gitignore исключает ненужные файлы из Git.
Фамилия -s tring, возраст — int, средний балл — double, отчислен или нет - bool.
Environment.ProcessorCount показывает число доступных процессоров. У соседнего компьютера оно может быть другим.
Console.ResetColor() возвращает обычный цвет консоли, чтобы следующий текст не остался цветным.
