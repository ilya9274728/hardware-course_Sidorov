1)dotnet build собирает программу. dotnet run собирает её и запускает.
2)После сборки в bin/Debug/net10.0/ обычно появляются файлы программы, отладки и настроек запуска.
3)Компилятор превращает C#-код в инструкции. Процессор не понимает текст C# напрямую.
4)gitignore исключает ненужные файлы из Git.
5)Фамилия -s tring, возраст — int, средний балл — double, отчислен или нет - bool.
6)Environment.ProcessorCount показывает число доступных процессоров. У соседнего компьютера оно может быть другим.
7)Console.ResetColor() возвращает обычный цвет консоли, чтобы следующий текст не остался цветным.
